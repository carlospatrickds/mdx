MD Studio

Um único aplicativo. Duas experiências Markdown desenhadas para objetivos diferentes.

📚

Modo Escolar

Leitura confortável, foco no conteúdo e apresentação didática. Ideal para roteiros, exercícios, estudos e materiais para crianças.

  • Fração visual empilhada
  • Tipografia de leitura
  • Checklist de estudo
  • Índice e navegação
  • Impressão limpa
⌘

Modo Técnico

Ambiente de autoria para documentos Markdown técnicos, documentação, código e conteúdos estruturados.

  • Editor + pré-visualização
  • Barra de formatação
  • Importação e arrastar/soltar
  • Outline do documento
  • Exportação Markdown
